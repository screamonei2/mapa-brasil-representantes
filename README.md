# Mapa Interativo do Brasil - Representantes

Sistema de mapa interativo usando Leaflet para visualização de representantes por estado e município.

## Como usar:
1. Inicie um servidor local
2. Abra o index.html
3. Clique nos estados para fazer zoom
4. Use a busca para encontrar representantes

## Tecnologias:
- Leaflet.js
- GeoJSON
- JavaScript ES6+
- CSS3
